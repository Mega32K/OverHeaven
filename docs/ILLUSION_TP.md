# illusionTp 深度扫描传送

已实现独立 `/illusionTp` 命令。服务端及目标玩家客户端均需安装含本功能的版本；命令权限等级为 2。命令不要求额外参数来控制深度灰色。

## 用法

```mcfunction
/illusionTp <targets> <x> <y> <z>
/illusionTp <targets> <x> <y> <z> in <dimension>
/illusionTp <targets> <destination>
```

- `targets`：玩家名或玩家选择器，例如 `@s`、`@a`。
- 坐标支持绝对坐标、`~` 相对坐标与 `^` 局部坐标；省略 `in` 时目的维度取执行上下文，指定 `in <dimension>` 时传送至该维度，支持维度补全。相对及局部坐标仍相对于命令执行上下文解析，追加 `in` 不缩放坐标。
- `destination`：单个实体，其位置和维度在命令执行时确定。
- 保留目标玩家传送瞬间的当前视角，不强制对齐目标实体朝向。
- 扫描先缓启动，再达到参考效果三倍时间轴的原有推进倍率，不需要 `in`、`duration`、`out`。

示例：

```mcfunction
/illusionTp @s 100 80 200
/illusionTp @a ~ ~10 ~
/illusionTp @s @e[type=minecraft:armor_stand,tag=arrival,limit=1]
/illusionTp @s 0 80 0 in minecraft:the_nether
/illusionTp @a 100 70 100 in minecraft:overworld
/execute in minecraft:the_nether run illusionTp @s 0 80 0
```

## 演出顺序

1. 锁定目标玩家位置；停止位移、跳跃和冲量，但保留自由转动视角。
2. 扫描按景物距离由近到远加速传播；天空按世界仰角由地平线向天顶纳入扫描。
3. 每处场景按自身被扫到的时间开始变化：原场景变为深度灰色后，以该处的扫到时刻加 0.25 秒作为纯灰截止时刻，按局部经过时间 smoothstep 淡成纯灰；早扫到的先完成，晚扫到的后完成。波前保留白色亮边及局部故障、色散。
4. 覆盖查询同时等待扫描波、glitch 边缘和淡灰尾带经过全部场景像素；实际绘制整屏纯灰 `#242424` 后才确认传送，不再在全屏扫描结束后额外统一淡出。等待传送时锁定纯灰，转头不会露出原场景。
5. 跨维度时保留本轮纯灰遮罩与位置锁，关闭旧世界的深度、手部副本和覆盖查询。此次切换的“加入世界”和“下载地形”界面在打开前移除；没有世界画面的强制渲染帧直接填充 `#242424`，不读取旧维度的纹理。目的维度、位置、区块接收和当前地形区段编译均就绪并连续绘制两帧后，从零启动反向材质过渡：每处在自身扫到时刻开始由纯灰逐渐恢复深度图，0.25 秒后由恢复边缘切回真实场景。没有整屏同步淡入；恢复边缘跟在深度显现之后，空间传播仍为向外扩散。就绪丢失时回到纯灰等待，恢复后重启。
6. 显现扫描及最后一处大块故障尾带消退并实际绘制后解除位置锁定。

深度灰色使用真实相机到表面的距离（格），按 `exp2(-距离 / 32)` 在远处 `#242424` 与近处 `#707070` 之间混合。天空保持 `#242424`，不使用远裁剪面伪造深度层次；全程覆盖不透明。

扫到时间由表面距离和实际扩散曲线反算，不用波后距离比例替代经过时间，也不把时间戳存为固定屏幕坐标上的历史纹理。渐变时长默认各处均为 0.25 秒，但开始和结束时刻各不相同；转头时重新对应当前真实场景的表面。

两道波均独立缓启动：前 1.5 秒将扫描推进倍率从原来的 20% 按 smoothstep 平滑提升至 100%，之后沿用原有三倍时间轴与平方扩散曲线。对推进倍率积分后计算半径，保证速度衔接连续；每道波结束缓启动后，扫描时间比原来滞后 0.6 秒。glitch 仍使用原来的 `Progress = elapsedSeconds * 3`，其播放节奏不变。实际总时长取决于景物深度和天空。

波前使用参考示例的 20 次光谱采样与横纵条带错位。亮边宽度严格为 `length(PixelSize) * 24.0`，由中心按原始 `smoothstep` 衰减，故障区域延伸至 `4.5 × width`；不增加最小宽度或导数扩边。故障仅短暂出现在波前附近，第一道波经过后留下逐渐褪为纯灰的深度轮廓，第二道波经过后留下实际场景。

窄带之外另有随机不规则强 glitch 与 RGB 色散：传送前作用于各像素即将被扫描到的前 0.35 秒；传送后从各像素恢复真实场景的时刻起持续 0.35 秒，在窗口两端平滑收敛。新增强化层及 Pixel Sorting 跳过深度为天空（`depth >= 1.0`）的像素，排序段在天空处截断，位移也不从天空取色；天空原有的扫描、灰色过渡、亮边和窄带 glitch 保留，完成时机不变。多尺度噪声叠加坐标扭曲形成大块不规则轮廓，实际作用区域按每个表面的扫描时间裁切，转头时不残留旧位置的故障。

不规则轮廓每 0.1 秒更新随机状态，同一时间片保持形状稳定，尺度随画面高度等比缩放。主体噪声尺度为 300×190 像素（1080p），降低形状阈值以扩大有效覆盖。轮廓内叠加双层动态噪声波、12 像素高的横向撕裂和粗尺度跳动，跳动项保留 45～155 像素的基础偏移；RGB 分离为 20～64 像素，均随局部强度渐变。排序后的画面也参与错位和 RGB 分离，不再用未色散的排序结果稀释故障层；彩噪幅度由 0.14 降为 0.025。新增层不进入原 `4.5 × width` 窄带；位移采样不读取屏幕外、手部及其一像素边缘、尚未恢复或已被遮蔽的场景，改用当前位置的安全排序结果或原色。

Pixel Sorting 采用水平方向的亮度阈值分段排序：阈值按 `0.04 + 0.14 * (0.5 + 0.5 * sin(elapsedSeconds * 5))` 在 0.04～0.18 之间变化，避免暗场景被大面积排除，低于阈值的像素形成边界；区域内按 `dot(RGB, vec3(0.299, 0.587, 0.114))` 从暗到亮稳定排序，相同亮度保留原顺序。排序使用原分辨率逐像素浮点亮度和完整 RGB，不降采样、不使用灰度直方图或拉伸重复采样。为限制每帧工作量，每个计算段最多 128 个原生像素，行尾不足时按二次幂拆分；手部、局部时间窗口及不规则形状边界同时截断排序段。最终将排序后的彩色条纹与强 glitch 混合。

参考为 [jianinz 的 Cyber Punk](https://www.shadertoy.com/view/7lVSDw) 的噪声波、扫描线及色散分层，以及 [FMS_Cat 的 20170723_pixelSorter](https://www.shadertoy.com/view/XsBfRG) 的水平阈值分段和稳定亮度排序。实现独立编写：使用有界并行排序网络替代参考中逐像素遍历整行、编码目标位置后再整行查找的流程；不再采用先前 `clc3zr` 的单通道直方图参考。

显现结束查询包含完整的 0.35 秒尾带，不因某个随机时间片没有故障块而提前结束；CPU 范围回退也采用相同延迟，但可见扫描波速度不变。纯灰等待、跨维度加载和目的地就绪丢失时不绘制新增故障。

第一人称手部、手持物、准星、快捷栏、血条和聊天不参与扫描。HUD 位于扫描合成之后；手部通过独立遮罩保留颜色。灰屏遮蔽期间转动视角不会重新露出场景。

## 接入与边界

- 命令、网络、状态与位置锁定集中于 `illusiontp` 模块。专用服务器的注册和网络类不引用客户端类。
- 服务端保存目的地；客户端只回传本轮标识及阶段确认。保留 Forge 传送事件取消/调整坐标行为。
- 支持主世界、下界、末地及服务端注册的自定义维度；使用原版跨维度传送与区块票据，跨维度事件被其他模组取消时清理演出，不发送成功抵达确认。网络包格式保持不变。
- 加载界面只在本次 `illusionTp` 已纯灰遮蔽且正在卸载旧维度时移除；普通登录、死亡复活、断线和其他传送不改变。世界实际加载仍会执行，画面以灰色等待。目标在建筑高度之外时无需等待不存在的地形区段编译。
- 同一玩家的 `illusionTp` 与 `pixelTp` 互斥；死亡、断线、超时、资源重载及其他传送中断会清理本轮。开始时脱离坐骑以保证位置锁定。
- 普通移动由双方的移动钩子限制；服务端收到的位置包保留旋转但不接受位置变化。不修改飞行权限、重力开关或游戏模式。
- 最终合成在 EndingLibrary 的 GUI 前后处理之后、HUD 之前进行；保留宿主后处理链与显示转换，不重新套用 gamma。
- 原版在手部深度清除前捕获场景深度；Oculus 1.8.0 在其管线完成前捕获实际深度，并在两次手部 pass 前后独立生成遮罩。Oculus 可选代码沿用既有版本守卫，不替换依赖。
- 当前实例的 EndingLibrary 2.2.1fix 没有 `DepthTestPostEffect` 测试类或示例 shader；以本地该示例的深度/天空/时间公式为视觉参考，在 OverHeaven 独立实现，没有调用实例中不存在的 API。
- 场景深度使用真实相机矩阵重建。GPU 覆盖查询异步读取，确认整屏已扫完后锁定遮蔽；远平面范围上界作保守回退。
- 排序只在有效扫描期间运行，复用本帧手部捕获结束后空闲的 `beforeHand` / `handScratch` 两个 R32F 目标保存精确索引，最终手部遮罩保持独立；不新增 GPU 目标，不从正在写入的附件取样。
- resize 时重建私有目标，取消、结束、资源重载及关闭时释放纹理、FBO、程序、采样器和查询对象；每次绘制恢复宿主 GL 状态。
