# 星空延时摄影：解析长曝光星轨

> 后续亮度、星轨长度分配和柔光增强见 [梦幻星轨](梦幻星轨-2026-10-29.md)。下文保留原始长曝光实现与当时的验证记录。

2026-10-29。演出星空在同一同步时钟上重建一段过去的旋转轨迹，不保存历史 framebuffer，不改变现有末段转速。奇点、黑洞和泡膜仍在星空之后绘制。

## 阶段编排

| 阶段 | 默认时间 | 曝光与观感 |
|---|---|---|
| 星空显露 | 40.9–44 秒 | 25 ms 短曝光，星点为主，白闪退去后可见细小尾光 |
| reverse | 44–60 秒 | 25→80 ms；随原旋转减速、反向自然收短并改变尾迹方向 |
| unweave | 60–88 秒 | 80→200 ms；亮星逐渐拉出弯曲长轨 |
| extinguish 前半 | 88–98 秒 | 200 ms；现有四倍终速在 93 秒达到，光轨最多 24° |
| extinguish 后半 | 98–108 秒 | 曝光时间与角长度预算同时平滑降至零；溶解缺口侵蚀银河、星点及尾迹 |
| silence / return | 108 秒以后 | 不保留星轨历史或残影，沿用既有纯黑和交还游戏 |

曲线为 smoothstep，各阶段时长调整后按归一化进度缩放。角度从 `FinaleChoreography.starMotion` 取值，超过 24° 时缩短有效快门窗口；逆转附近按实际转折计算总角路程，避免用首尾差抵消真实路径。

## 星轨与曝光

`FinaleStarExposure` 保留可复用角样本数组，`StarExposureUniforms` 上传到现有星空 shader。每帧求值一次，渲染器退出/重载时清空。没有新增命令、网络字段、配置、存档格式、纹理或渲染目标。

低/均衡/高档分别使用 1,024/2,048/4,096 颗星，4/8/12 段轨迹。亮度排序前四分之一使用完整快门；其余使用 35% 的有效快门，形成约 35% 长度的短尾。轨迹中心直接由天球旋转和当前相机矩阵投影。

每颗星以 40% 光能分配到清晰头部，60% 分配到尾迹；尾迹的归一化快门权重为 `2*(1-t)`。各段采用积分高斯线核，不以重复光点堆积成线；增加分段数不改变总光能，反转或旋转轴附近轨迹收至一点时也不重复增亮。

每段独立执行齐次视野和近裁剪面检查，头部在屏外或相机后方时仍保留可见尾段。屏幕边界不会钳制纹理坐标或制造边缘亮线。

银河在现有低分辨率目标中使用 85% 当前采样、15% 历史角方向平均。曝光窗口为有效星轨窗口的四分之一，低/均衡/高档增加 1/2/3 次纹理采样，继续使用经度接缝与极点的显式 LOD 计算。

## 溶解与资源

源星在当前时刻已经溶解时，头部和全部尾段都不绘制。尾段像素再按当前相机方向检查溶解场，因此历史轨迹不会填回黑色缺口。银河的历史采样与最终输出方向同样检查当前溶解状态。

NASA 加载失败时保留程序星空的短轨路径，套用同一曝光强弱和退场包络；诊断为 `procedural-short-trails`。不为备用路径增加全屏多次星场求解。

暂停冻结角度和快门；晚加入直接重建当前轨迹。中止由既有世界/宇宙恢复包络控制；纯黑、白闪和主体分层顺序不变。GL 状态、资源缩放和释放继续使用原有拥有者。
