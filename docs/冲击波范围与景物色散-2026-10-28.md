## 当前表现

相对前轮共享传播版本，七道冲击波终点半径全部乘 2、传播速度乘 1.5。发射时刻、白闪、星空接管和八阶段时长不变。最后一波仍是普通波的双倍范围。

默认 radius=3.2、outer=11、thickness=.16 时：

| 项目 | 前轮 | 本轮 |
|---|---:|---:|
| 普通波终点半径 | 12.298 格 | 24.596 格 |
| 最终波终点半径 | 24.596 格 | 49.192 格 |
| 最终波延长段速度 | 4.218 格/秒 | 6.327 格/秒 |
| 最终波开始 | 40.4 秒 | 40.4 秒 |
| 最终波结束 | 45.116 秒 | 47.431 秒 |

速度与距离分开实现：原启动传播曲线时间除以 1.5，随后沿其末端速度继续向外，直到新的终点半径。没有同时缩短时间并把启动半径曲线乘二，因此不会误变成 3 倍速度。蓄压、推出、末端破碎仍存在；消散按新的完整寿命计算。Java 波前同时供渲染、裁剪、相机穿越与预兆使用。

最终波的色散主要作用于它周围的背景景物。有限色散带覆盖亮波前内外两侧，单侧宽度为 max(基础半径×.45, 当前波半径×.18)。将 RGB 采样偏移及保亮度的光谱变色加强，1080p 单通道上限 40 像素，红蓝最大间隔约 80 像素；其它分辨率同比缩放，并保留像素等向上限。波前发光与奇点本体随后单独合成，不为它们额外染色。此次不改变原有全屏镜头色散的 8 像素预算、12 格渐强和穿越后 .4 秒退场。

深度检查覆盖每个额外 RGB 采样的双线性足迹，检查屏幕边界与透明源。不能可靠采样时退回已成立的引力透镜画面。裁剪支持范围包含外侧色散带与波面碎屑；主体体积积分范围及采样预算没有增加，也没有新增渲染目标、纹理、网络字段或逐帧对象。

## 代码

- `src/main/java/com/mega/overheaven/foliagecompat/finale/FinaleWaves.java`：独立速度/范围倍率、所有波的末端延长、色散带裁剪支持。
- `src/main/resources/assets/overheaven_foliage_compat/shaders/blackhole/finale_energy.glsl`：围绕最终波前的有限景物色散带、像素偏移上限。
- `src/main/resources/assets/overheaven_foliage_compat/shaders/blackhole/composite.fsh`：增强背景光谱分离；失败采样回退至有效透镜背景。
- `FinaleFeedbackVerification`、`ShockwaveGpuVerification`、`WaveRangeSpectrumGpuVerification`：共同传播、完整生命周期、景物色散及回退对照。

## 验证结果

- Java 17 针对性编译通过；未调用 jar、build 或 reobfJar。
- 31,653 条波前/相机反馈断言通过，覆盖七道波范围、1.5 倍速度、末端速度连续、扩大后范围内的镜头穿越、低帧率、暂停、晚加入和校时重建。多种尺寸及阶段时长验证波之间不重叠，避免单波求值器吞掉后续发射。
- 新增 27 项独立 GPU 检查通过：生产 shader 编译、景物变化、色散作用于亮球面外侧、前段光辐射不因色散开关变化、整墙/半墙、透明接收层、暂停、抬头/背向/中心相机、24/48/96 步及 40/70/110° FOV。
- 现有冲击波、基础引力透镜、最终白闪/宇宙分层、演出时序与数据、植物兼容/委托/守卫检查通过。时序与数据检查为 4,230 项，植物 API/侧隔离为 102 项，守卫为 38 项。
- 同场景最大通道偏移从约 5.15 像素增至 40 像素。与关闭色散的画面比较，平均绝对 RGB 变化由 .001365 增至 .011275。该数值只描述固定测试画面的变化，不是视觉效果的通用物理量。
- 旧透镜回归夹具随新生命周期更新：源玻璃必须位于采样源，并与接收像素分离；回退场景使用相同启动曲线半径，完整生命周期另行检查。保留了初次失败日志及修正后的完整通过日志。
