# 冲击波修复与验证

日期：2026-10-27。对应用户确认：“先这样做”。本轮只实施冲击波修正，星点密度／清晰度与外围能量线的替代设计留到下一项。

## 证据与根因

修改前快照：`audit/shockwave-2026-10-27/before/`。

- 源码事实：`field.glsl` 先建立引力透镜的 UV 与背景有效距离。旧 `energyFront` 随后使用未偏折的原始 ray 重新投影并覆盖这两项；弱波面内部同样会写入。这不是单纯亮度问题。
- GPU 重现：将生产 shader 的波前函数在测试夹具中开关，旧版 UV／深度元数据出现差异，格子背景在波面内恢复为近似未偏折状态；对照图上排可直接观察。测试对旧版要求检测出缺陷，避免仅验证修正版自洽。
- 修正版：相同相机／时间下，有波和无波的基础透镜 UV、背景有效距离逐值一致。50 组时间／视角覆盖了波前出现、消散、正视、抬头、背向与摄像机位于范围内。
- 限定：以上是本机独立 OpenGL 场景的重现与验证；未启动 Minecraft，不能替代宿主后处理和实际透明物体的游戏内验收。

## 实现

生产改动仅为两份 shader：`finale_energy.glsl` 和 `composite.fsh`。

1. 冲击波辐射不再写入基础透镜坐标或背景有效距离。新 `energyRefraction` 在全分辨率合成阶段，依据局部波面法线对已经引力偏折的方向作小角度扰动，再投影；没有简单相加两个屏幕 UV 偏移。
2. 先完成原透镜背景采样，再尝试波面采样。沿用屏幕边缘渐隐、源像素完整双线性足迹深度检查、透明源层拒绝与低分辨率重建置信度。额外采样失败时回退到已完成的透镜颜色，不回退到原始屏幕。波的有效距离取原透镜约束与实际波前距离的最大值。
3. 透明接收像素仍单独保留宿主表面辐射，只偏折后方不透明／天空颜色。波面发光继续走 `finaleLight` 的前后段分离。不会把玻璃当实心墙，也不把未解析的透明源颜色搬到另一像素。
4. 波前前 9% 寿命短暂向内蓄压，然后快速推出。传播为指数冲量与线性外移的组合，终点速度仍大于零。后方约 2.4% 支持半径处跟随短尾浪。
5. 48%–88% 寿命按世界方向中的稳定图案逐块撕开。少量碎光继续移到波前之外；94%–100% 才收尽余辉，半径仍在增加。没有每帧随机噪声或 atan 接缝。碎光最外沿被限制在既有渲染支持范围内。
6. 保持所有原有 SUMMON／FRACTURE 的归一化触发点。没有改阶段长度、同步协议、命令、声音提示、最终白闪、奇点膜层或场景接入顺序。

性能结构：最多三层解析球面发光和两层局部折射评估。未增加体积采样步数、渲染目标、采集 pass、粒子实体或生产环境 GPU 回读。没有活动波时立即跳过其计算；透镜有效性与波前折射在最终分辨率处理。

## 检查结果

只执行显式验证任务，没有执行 `build`、`check`、`jar` 或 `reobfJar`。

- `compileJava` / `compileVerificationJava`：通过，Java 17；主 Java 无修改。
- `verifyShockwaveGpu`：322 次断言通过，含旧版缺陷重现、基础透镜保持、前景／透明源拒绝时回退、整墙／半墙、范围内／抬头／背向、暂停确定性、摄像机位于精确球心时的有限辐射、透明前后段与 24／48／96 步波面亮度一致性。
- `verifyFinale`、`verifyFinaleChoreography`、`verifyFinaleRecovery`：时间线、同步／存档／命令约束、时长变化、暂停、静音与玻璃恢复回归通过。
- `verifyFinaleFlashGpu`、`verifySingularityGpu`：生产 shader 链接、实际选定 Complementary 星源、白闪／宇宙分层、奇点、质量切换、GL 状态与 GPU 资源释放／重建回归通过。
- `verifyBlackHoleLens`、`verifyBlackHoleEnvironment`：近距离透镜、环境层与范围内抬头回归通过。
- `verifyBlackHole`、`verifyBlackHoleContracts`、`verifyCompatibility`、`verifyDelegation`、`verifyGuard`：普通黑洞、实际外部符号、客户端隔离及植物兼容回归通过。
- `field.glsl` 与修改前逐字一致，奇点本体、泡膜、普通黑洞材质与基础引力映射未改。
- 当前工作树 `git diff --check`、本轮快照差异检查、UTF-8／空白检查通过。预先存在的无关源码、卡牌素材、日志、实例 ZIP、已有 JAR 的哈希保持不变。

测试说明：质量档位的比较只针对波前辐射；不把原有会随档位改变数量的外围线束纳入波面亮度比较。GPU 断言次数包含重复视角、采样点和时间点，并不等于 322 种独立游戏场景。
