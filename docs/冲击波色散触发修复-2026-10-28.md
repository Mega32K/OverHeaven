# 冲击波景物色散：前六波触发遗漏修复

> 后续已进一步扩大色散宽度与强度，当前参数见 [色散增幅](冲击波色散增幅-2026-10-28.md)。本记录保留触发条件修复时的参数与证据。

日期：2026-10-28。仅源码、开发输出和针对性验证；未生成 JAR，未自动启动或操作游戏，未安装文件、改光影 ZIP、改实例配置、提交或推送。

## 找到的问题

上一版 energySpectrum 的返回条件包含 WaveFinal==0。这会让前六道波的局部景物色散直接返回零；扩大偏移和色散带也无法改变它。上一轮 GPU 主要检查了最终波，遗漏了前六波触发覆盖。

现场只读核对：当前开发客户端通过 forgeclientuserdev 加载 build/classes/java/main 和 build/resources/main，启动于 2026-10-28 06:54:50；上一轮 shader 和 Java 编译输出在 06:43 左右已更新。启动前的 shader 源文件与开发输出 SHA-256 一致，未发现运行旧资源的迹象。日志显示使用 ComplementaryUnbound_r5.9.3.zip，并在 07:13:25.768 完成演出准备。截图仍含宿主地形；没有该帧准确的波 ID/ticks 记录，不能把图像本身当作精确阶段证明。

GPU 回归直接复现了旧条件的行为：前六波开启/关闭色散得到相同画面；当前七波都有景物变化。此为代码根因与独立验证证据，实际宿主画面仍需用户重试。

## 修复

- 删除仅最终波才允许局部色散的条件。普通波为当前局部色散强度的 85%，最终波保留 100%。仅在存在有效波前时运行。
- 每道波的解析裁剪支持范围均纳入外侧色散带；范围×2、速度×1.5、各发射时刻、白闪与阶段时长不变。
- 保持背景景物 RGB 分离，随后再合成奇点和波面发光。玻璃/水前后段、额外采样深度保护、基础透镜回退不变。
- 全屏镜头色散仍只由最终波的 12 格接近与穿越后 .4 秒包络控制；没有把局部波面色散变成持续全屏效果。
- 没有新增运行时 uniform、配置、网络或存档字段。验证管线通过仅测试源码注入的 TestSpectrumDisabled 独立禁用色散，不再把 WaveFinal=0 当成色散测试开关；生产资源中不含此测试 uniform。

生产改动仅为 FinaleWaves.java 的裁剪支持，以及 finale_energy.glsl 的触发和普通波强度。验证调整位于 FinaleFlashGpuVerification 与 WaveRangeSpectrumGpuVerification。
