# 透镜仅查询当前视图可恢复的世界背景

2026-10-26：用户授权采用推荐路线。透镜重构以当前帧可验证的颜色和深度查询世界背景，遇到屏外、被遮挡或缺少可信层信息的背景时明确退化，保留可确定的主体辐射。暂不增加侧面/背面世界重渲染、环境立方体或历史帧背景，以控制 RTX 3060 的渲染成本及 Oculus/EndingLibrary 接入范围。

这意味着近距离透镜无法保证显示玩家身后或完全不可见的真实地形。未来若改变此边界，必须重新设计捕获、视差、透明层和宿主兼容，不能只撤销源有效性检查。详细方案见 ../LENS_REDESIGN.md；该决策已接受，渲染实现尚未重构。
