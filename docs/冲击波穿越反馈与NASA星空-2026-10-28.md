# 冲击波穿越反馈、耀眼十字星芒与 NASA 全天星空

> 本文记录前轮实现。随后追加的全部冲击波范围 ×2、速度 ×1.5 与周围景物色散增强，见 [范围与色散修订](冲击波范围与景物色散-2026-10-28.md)。本文旧数值与证据保留用于追溯。

日期：2026-10-28。源码交付；没有生成新 JAR，没有启动 Minecraft，没有改动实例、光影 ZIP 或既有 JAR，没有提交或推送。保留了修改前已有的未提交内容。

## 本轮表现

- 七次波的发射时刻不变，沿用 SUMMON 的 .06/.37/.66 与 FRACTURE 的 .10/.36/.62/.80。将原传播时间减半；半径曲线保留蓄压、推出与正向末端速度。
- 最后一波先走相同的普通范围曲线，再以末端速度外推至双倍半径。默认普通波终点 12.298 格，最后一波终点 24.596 格；最终波从 808 tick（40.4 秒）开始，约 902.311 tick（45.116 秒）消散，跨过 880 tick 的 reverse 起点。延长部分约 4.218 格/秒，没有把整条半径曲线乘二。
- 波面发光、额外折射和相机穿越共用 FinaleWaves 的状态。末端破碎按整道波的自身寿命推进，解析球面与裁剪支持范围同步更新；普通黑洞体积积分和基础透镜函数不变。
- 实际相机的距离减波前半径由正变负时触发短震：普通波 0.35 秒，最终波 0.5 秒。pitch/yaw/roll 上限分别为 1.0/.6/.45 度、1.6/.9/.7 度。通过 Forge ViewportEvent.ComputeCameraAngles 叠加事件角度，不改玩家朝向、位置或 FOV。
- 穿越增亮在 0.02 秒内达到约 .6/.9 EV 的显示响应，0.2 秒时归零。使用显示空间有界提亮，保留宿主已完成的显示转换；不把已处理画面当原始 HDR 再映射。
- 最终波的轮廓局部做光谱分离与保留亮度的变色，仍逐通道检查采样深度与透明源。相机位于波前之外 12 格内时色散渐强；穿越后 0.4 秒内归零。波寿命末尾同时衰减预兆，避免停在范围外的观众在波消失时突然掉色。
- 镜头色散中心弱、边缘强；1080p 最大红／蓝通道偏移约 8 像素。波面炫彩与镜头色散独立，最终全白与纯黑覆盖在它们之后。
- 十字细芒线性辐射为原值 3 倍，柔光为 1.8 倍。发射时增加最多 30% 的短包络，不持续周期闪烁。保留基础半径距离曲线、四臂像素等长、glow 控制和九点遮挡；默认 16 格内新增远景层仍为零。

## 生命周期、层次与接口

相机反馈不依赖奇点是否投影到屏内。每道波仅一次；低帧率使用区间和二分求穿越时刻，过时的瞬时亮度不会在恢复帧率后重播。服务端校时跳变、初次加入、切换维度、相机实体变化、F5 视角切换和传送均重新建立穿越基线。暂停冻结正在进行的反馈；中止、断线、资源重载、失败清理状态。

客户端新增 FinaleCameraResetMixin，在 ClientPacketListener.handleMovePlayer(ClientboundPlayerPositionPacket) 与 handleSetCamera(ClientboundSetCameraPacket) 的 RETURN 清理反馈。两个完整描述符均从实际 Forge 47.4.10 映射 JAR 核实；RETURN 位于原版主线程处理和移动之后。注入只位于 mixin 配置的 client 列表，生成 refmap 分别映射至 m_5682_ 和 m_6447_。不添加网络包、字段、命令、配置或存档迁移。

合成仍为全天星空 → 奇点／黑洞及透镜／辉光 → 镜头色散与增亮 → 最终白闪／纯黑。沿用原世界与宇宙输入分层，以及 EndingLibrary 之后的晚期合成边界。原版／Oculus 正常世界的深度、前后透明分段与 HDR 路径保持原状；本轮不更改宿主后处理。

## 天空资源与来源

- 来源：NASA SVS Deep Star Maps 2020，https://svs.gsfc.nasa.gov/4851/ 。原始素材为分开的 milkyway_2020_8k.exr 与 hiptyc_2020_8k.exr。
- 署名：NASA/Goddard Space Flight Center Scientific Visualization Studio；Ernie Wright (USRA)；Gaia DR2: ESA/Gaia/DPAC。
- 使用说明 https://svs.gsfc.nasa.gov/help/ 声明未另行标注的 SVS 内容为公有领域。只使用星图，没有使用星座线图、音乐、标志或视频。来源页面副本保存在 audit/wave-feedback-sky-2026-10-28/source/。
- tools/prepare_finale_sky.py 将银河背景滤波并缩为 4096×2048，保存为线性 RGB9_E5；原始星图的亮源按积分亮度确定性排序、去重并提取 4,096 条方向／颜色／视觉亮度数据。它不是可替代科学星表的数据集。
- 低／均衡／高档画 1,024／2,048／4,096 颗亮星，使用同一个实例化几何批次。背景可降分辨率，亮星始终在全分辨率目标上画，随固定世界轴旋转，保留有限星轨和三个末段星群的先后熄灭。
- 演出在开关光影时都使用新资源，正常世界天空不变。光影 ZIP、Oculus 适配器和原有光影星点 shader 未修改。旧 FinaleSky 适配器及其独立测试保留为历史兼容代码，不代表现演出还按光影开关切换星源。
- 资源解压在线程池预载，演出初期渲染线程预热上传，避免到白闪切换才加载。缺失／损坏时只记录一次错误并回退原程序星空；重载可恢复。无演出不执行新增 pass。
- 派生资源约 30.58 MiB：背景 31,969,056 字节、亮星 94,390 字节；静态背景 GPU 内存含 mip 约 42.67 MiB，亮星约 112 KiB。CPU 上传副本不长期保留，没有运行时联网。
- textures/finale/SOURCE.json 记录原始和派生文件 SHA-256；NOTICE.txt 随模组资源分发。生产 Java 无新增库依赖；离线 Python 依赖仅用于素材处理。
