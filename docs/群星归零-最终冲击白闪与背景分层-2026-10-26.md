# 《群星归零》最终冲击白闪与星空分层（2026-10-26）

本轮已实现并完成针对性编译和独立 GPU 检查。没有生成新 JAR、启动 Minecraft、安装实例文件、改动实例配置、提交或推送。Minecraft 1.20.1、Forge 47.4.10、Java 17、包名和现有 FG 远程依赖保持不变。

## 时间与行为

冲击起点为 `fracture` 阶段 80%，默认第 **40.4 秒（808 tick）**。保留原有八阶段与 120 秒默认总时长。

| 相对冲击时间 | 白光强度 | 背景与主体 |
|---|---:|---|
| 触发前／0 秒 | 0 | 正常世界遮挡 |
| 0.25 秒 | 0.0625 | 奇点局部辐射增强；世界仍在 |
| 0.5 秒 | 1 | 全白，切换到星空背景与独立主体 |
| 0.6 秒 | 1 | 全白停留结束 |
| 0.7 秒 | 0.0625 | 露出星空、主体与短暂柔光 |
| 0.8 秒 | 0 | 正常曝光，无永久增亮 |

上升 `t^4`，退去 `(1-t)^4`。白闪窗口固定 10/2/4 tick；修改 fracture 时长只移动起点，窗口可以跨入 reverse。无玻璃同样触发曝光，玻璃声音与碎片仍按真实选区决定。

`unweave` 不再拆地形片层或渐入星空，改为已经存在的星空下奇点泡膜和焦点收束；extinguish 延续原星区熄灭，silence 微弱轮廓来自主体通道，后 37.5% 维持纯黑。return 按原缓入缓出覆盖包络交还世界，不重复叠加主体。

暂停冻结同步 elapsed 和白闪；恢复连续推进。停止以当前服务端 elapsed 的曝光和覆盖度为起点，在既有 40 tick 恢复窗内衰减；晚加入直接用包内 elapsed/stopping 重建，无需新增字段。删除或移动演出源时，停止过渡保留演出快照位置，避免普通黑洞记录先消失造成主体突然跳走。

## 渲染路径

顺序为 **星空背景 → 黑洞／奇点、透镜、泡膜与辉光 → 最终白闪**。

- 白闪前，普通路径保留地形、实体和透明表面的深度分段。
- 全白时生成独立宇宙目标，星空完成自身显示转换后，交给同一套黑洞求解／辉光实现的独立实例；主体使用显示空间合成，不再次转换整张星空。
- 宇宙输入显式提供远深度和单位透射率，透镜偏折星空，黑核截断背景。晚期合成不再读取世界深度。
- 当前维度其他可见黑洞继续按原距离顺序独立求解，保留真实相机、世界位置、距离和屏幕范围剔除，没有新增联合引力场。
- 完整接管时普通世界黑洞求解全部跳过。停止和恢复时分别完成世界／宇宙图像，再加权混合完整图像；最终纯黑优先于所有主体和曝光。
- 裂纹、碎片和逆流仍使用原合批几何；宇宙段使用宇宙空深度，不被已隐藏建筑挡住。
- 局部强光始终来自奇点真实位置。全屏曝光不依赖奇点可见性，不钳制屏外中心。
- 新目标复用、缩放并由 FinaleRenderer 释放；独立主体实例关闭时不重置宿主 Oculus 会话。不存在演出／曝光时不执行新增晚期 pass。

光影关闭时用模组星空；开启时继续使用已核对 Complementary 的全球星点路径。两个星空 shader 均不再包含奇点残影。EndingLibrary 及原 GameRenderer 晚期注入点未修改；没有更换宿主全局后处理链。

常态辉光仍服从 `glow`；冲击期间使用独立临时辐射与辉光包络，结束恢复原值，不写黑洞记录。

## 性能

RTX 3060，1920×1080，均衡 48 步／半分辨率。完整夹具测星空、单主体、辉光与最终合成，排除游戏宿主、场景采集、CPU 和服务器。碎片在独立回归测试；此计时不含真实玻璃现场。

| 阶段采样 | 本轮单次短测 ms/帧 |
|---|---:|
| fracture，白闪退去后 | 1.840 |
| reverse | 1.830 |
| unweave | 1.738 |
| extinguish | 1.677 |
| silence，微弱轮廓 | 1.536 |
| silence，纯黑 | 0.215 |
| return | 0.554 |

同一上下文、相同视角、extinguish 固定帧：修改前快照 **0.422 ms**，新版 **1.603 ms**，差值 **+1.182 ms**。旧版此时不绘制完整主体，仅星空与简化残影；新版增加真实主体与辉光。它反映修复的夹具成本，不是游戏 FPS 承诺。早期 expose/summon 的夹具也强行绘制星空以测 shader，不代表生产路径在该阶段执行宇宙 pass。
