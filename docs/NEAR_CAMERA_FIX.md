# 近距离黑洞背景条带和前景重影修复（2026-10-26）

## 已观察事实与定位

用户截图中可见矩形状重复背景，以及正常手部上方的第二份手部图像。截图本身不能证明当前光影开关或最终合成路径。

本轮读取的开发日志记录了 Oculus 1.8.0 与 ComplementaryUnbound_r5.9.3.zip；配置落盘时 enableShaders=false，不能据此认定截图时光影关闭。未启动游戏。

修改前的生产 shader 有两处可复现的缺陷：

1. field.glsl 在偏折目标接近屏幕边缘时，混合原始 UV 与偏折 UV。这个连续回拉会扫描两点之间的其他画面；靠近黑洞、偏折目标跨出屏幕时，出现折返条带。
2. composite.fsh 仅比较采样源深度与当前射线的影响球入口。相机位于影响球内部时，入口被截成 0，几乎任何前景源都能通过。这样可以把靠近相机的手部搬到远处像素。

精确版本字节码核对：实际 Oculus 1.8.0 的 MixinLevelRenderer.iris$beginTranslucents 顺序是 beginHand → HandRenderer.renderSolid → beginTranslucents。本项目在后者 TAIL 采集，所以不能继承原版“采集发生在手部之前”的假设。字节码文本保存在本次 audit 的 engine/，原 JAR 来自项目固定的 Modrinth Maven 工件。

修改前的实际生产 shader 在独立 GPU 夹具里复现了前景复制及边界折返。这个证据证明代码缺陷及其修复，不代替该 Minecraft 场景的运行验证。

## 修复机制

生产改动仅在 field.glsl 和 composite.fsh：

- 保留实际偏折投影 UV，在屏幕边缘混合采样后的颜色；越界、位于相机背后或无有效投影时使用原背景。
- 低分辨率重建不再把无效投影的原始 UV 混入有效偏折 UV。使用单独的有效权重，避免在重建阶段再次扫过无关背景。
- meta.w 从未被其他 pass 使用的影响球入口改为最小合法背景距离，保留 -1 作为无效标记。
- 有地形终点时使用重投影终点距离；原始射线朝向天空时使用已走过的弯曲场出口距离。天空射线仍可采样位于场出口之后的地形，未按天空/地面分类关闭透镜。
- 对偏折采样的完整四 texel 深度足迹做前景检查，拒绝近于该距离的来源。相机进入影响球后仍有效；任一近处手部/实体/地形 texel 都能触发回退。

黑核、前后盘辐射、透明分层和原有高分辨率遮挡继续使用现有路径。没有增加 GPU pass、渲染目标或纹理单元，没有改变 Oculus/EndingLibrary 注入时序或植物补丁。

屏幕空间采样无法恢复屏幕之外或被近处物体遮住的远处背景。这些无可用来源的像素回退原背景，仍保留黑核及盘面；不会伪造隐藏场景，也不承诺具备多视点环境捕获的透镜精度。

- 定向检查屏幕边界颜色混合、无效低分辨率邻点、近处来源拒绝、四个深度 texel 分别受污染，以及有效近距离偏折和天空到远处地形的偏折仍存在。
