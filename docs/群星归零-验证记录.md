## 独立 GPU 测量

本机 NVIDIA GeForce RTX 3060，1920×1080 输出，960×540 求解，固定 seed/time。短测试先暖机再计时；这些数值用于预算检查，不是 Minecraft 帧时间承诺。未计入场景副本、宿主世界、光影、后处理、玻璃碎片完整场景或服务端操作。

| 阶段 | 测量内容 | 最近一次 ms/frame |
|---|---|---:|
| expose | 近景求解 + 辉光 + 合成 | 1.026 |
| summon | 同上 | 1.121 |
| fracture | 同上，不含实际现场碎片 | 1.910 |
| reverse | 同上 | 3.520 |
| unweave | 星幕求解 + 片层合成 | 0.446–0.460 |
| extinguish | 星幕求解 + 片层合成 | 0.439–0.446 |
| silence | 暗丝 / 完全黑场 | 0.440 / 0.076 |
| return | 星幕求解 + 片层合成 | 0.453 |

重复短测的近景值有波动，例如 reverse 之前为约 1.99 ms；不能据单次微基准推断实机峰值。当前全场耗时、服务器扫描与恢复耗时均尚未测量。运行时可用 /blackholeclient diagnostics true 观察自有 GPU pass，服务端 finale status 显示扫描/恢复计时与恢复队列。
