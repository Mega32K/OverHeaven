# 引力透镜重新设计：可验证的当前帧背景查询

日期：2026-10-26。状态：历史设计，其深度追踪实现已按用户要求撤回。当前采用更低开销的独立环境方向映射，见 [环境透镜修复记录](LENS_ENVIRONMENT_FIX.md)。下文不代表当前发行实现或运行效果认证。

## 范围与目标

以 minecraft-black-hole skill 的世界空间、相机、前景保护和资源生命周期约束为基础，保留本项目严格地形遮挡、原版/Oculus 前后段合成和 EndingLibrary 时序。skill 示例的美术遮挡策略与未认证光影接入不直接移植。

目标是靠近中心、抬头、环绕观察时不出现没有对应射线的大块地形条带；正常区域保留连续透镜变形。保持既有盘面、0–50% 内侧色度曲线、局部薄雾和 HDR 辉光。不新增命令、网络字段、存档迁移、外部素材或额外世界重渲染。只支持现有已核对的光影路径，不能扩大兼容声明。

## 现有代码已观察事实

- field.glsl 用直线与影响球、核心的交点，以及原像素深度共同决定 finish；后续 position/velocity 却沿弯曲路径推进。
- 循环可因剩余透射率低而退出；背景投影的条件没有区分影响球退出、低透射率退出和预算耗尽。
- 背景 endpoint 使用原像素距离（天空取 4096）沿末端方向外推；这不是与实际源位置深度的求交。
- composite.fsh 的源距离下限和四 tap 前景拒绝能防止部分近物复制，但不能证明采样点落在该弯曲路径上。
- 最近的主导 UV 邻居保护修复了一个可复现插值反例；它不验证积分路径，也不证明用户截图仅由该缺陷引起。
- BlackHoleRenderer 的 opaque、transparent、scene 有不同采集阶段。最终画面的云层不能被假定都存在于 opaque 中；需要检查实际捕获内容。不能把无深度颜色一律叫作无限远天空。

## 确定的架构

相机光线 → 有界弯曲路径 → 路径事件判定 → 当前帧场景查询 → 验证命中与采样足迹 → 按命中类别重建 → 原有分层合成。

### 1. 相机与路径

沿用实际 VP、InverseVP 和光学眼点，所有位置使用同一相机相对世界轴坐标。保留 bob/hurt/非对称投影测试。方向用方向变换，点用点变换；不得从只含投影的矩阵推导整个实际观察关系。

球体解析相交仅用于入口、剔除与全分辨率直视核心轮廓。采用有界中点/预测修正弯曲积分，保留当前艺术偏折强度的初始标定，不宣称精确相对论。每段检查真实段与核心球、影响球的相交，按发生次序处理最早事件；命中位置裁剪该段积分长度，不能越过核心后才丢弃整段近侧辐射。开始点在核心内时按核心捕获处理。

步长受曲率、距核心距离和段投影跨度约束；每档总预算固定。边界不满足误差约束且没有剩余预算时返回 Unresolved，不能把最后位置冒充已离开影响区。影响区边缘的加速度采用固定比例平滑衰减带，避免跨边界时突然启停偏折；球边内外视点必须做连续性验收。

盘光不再决定背景有效性。可停止颜色累积后继续廉价路径/背景追踪；若选择完全终止整条射线，则必须将背景判为 Unresolved，并保留已积分的近侧辐射。不得以停止发光为理由输出虚构出口。

### 2. 场景查询与有限深度命中

沿弯曲段和离开影响区后的直线段，查询同一当前帧颜色/深度快照。首先实现有上限的屏幕空间分段搜索；不引入深度金字塔或时间历史，避免同时增加多个未验证系统。

各段投影前先裁剪近面并检查齐次 w；对可见段按屏幕投影进度分段，使用透视正确参数重建候选世界位置。每次查询获取源像素的线性视深度以及逆投影世界位置。段的视深度跨过可见表面、且候选与重建表面的距离在与像素足迹相关的有限容差内，才能进入细化。

一次命中最多 3 次区间细化，计入总查询预算。不能仅凭相邻深度符号变化认定命中：两个采样若跨越深度轮廓或对象分离，无法建立可靠同一表面区间时返回不确定。近面穿越、后向投影、画面外、预算不足和非有限数值都有显式失败状态。

每段的核心事件与场景命中按路径参数排序。虽然只采集相机可见第一层表面，仍需检查影响区内部的地形，不能只在离开球之后查询。对于直视前景和主体的遮挡继续采用项目现有全分辨率保护规则；其作用是保守的合成约束，不把原像素的相机距离当作弯曲路径长度。

主视图的 depth 不包含完整世界，因此“没有找到命中”不等于“射线一定没有被挡住”。投影轨迹穿过不可恢复的遮挡区时，不继续猜测背后颜色。容差只用于数值与像素足迹误差，不作为把墙当厚体积、扩大穿透范围的手段。

### 3. 远场与未知背景

只在路径已确认离开影响区、离开方向可投影到当前画面、相关查询未出现未知遮挡、且宿主输入能够确认是远场层时，按出射方向查询远场颜色。采用方向投影，不再构造固定 4096 世界点。

深度 clear 值只能说明没有可用有限深度，不能独自证明颜色是天空：云、天气、光影背景都可能缺少可用深度。无法可靠识别的此类层按 Unknown 处理，保留原像素宿主表现，不伪造云层深度、不复制盘面、不把 terrain 强行当远场。

不额外捕获侧面/背面，不建立环境立方体，不保留上一帧颜色。屏外及被遮挡世界信息暂不恢复。原版和 Oculus 适配器分别明确其输入的颜色阶段、深度空间和远场可信条件；不支持的布局沿用明确诊断和安全跳过。

### 4. 结果数据与有效性

建议结果类别为 Core、Surface、FarField、Unresolved；另保留失败原因：OutOfView、NearPlane、OccludedUnknown、BudgetExceeded、NonFinite、UnsupportedLayer。类别与失败码是设计名，不代表已有 Java/GLSL API。

每条结果保存：源 UV（仅有效命中）、源距离/命中校验数据、类别、可信度、原像素深度状态，以及现有前后段辐射/透射。核心结果不能带有效背景源。完整数据格式在实现前列出 Java、GLSL、clear 值和纹理单元对照表。

优先复用现有四 MRT；若字段无法无损容纳，增加一个求解分辨率的元数据附件，不把语义硬塞进已经被 bloom 使用的距离通道。检查实际最大 draw buffers/attachments，增加纹理单元时同步 GlState 捕获范围与测试。源 UV 使用足够精度（优先 RG32F）以避免近距离半精度量化被误诊为路径跳变。资源额外成本须记录。

### 5. 重建与全分辨率遮挡

首先保留全分辨率直视核心轮廓与目标像素场景遮挡，再重建低分辨率辐射。背景邻居只有类别一致、目标深度状态匹配、源位置连续、源深度也连续时才允许插值。

Surface 不与 FarField、Core 或 Unresolved 混合。插值后重新验证采样足迹的源深度，防止跨物体颜色泄漏。辐射/透射重建与背景源选择分别处理，避免仅背景不可靠就丢弃正确近侧盘光。

不连续时先使用同类别的主导有效邻居；如果与当前像素无法建立一致关系，则返回原始背景。首版不在每个全分辨率失败像素无限重跑积分；后续只有测量证明必要且可限定成本时才引入局部修正。主导邻居切换的离散边缘必须纳入移动视角测试。

可信度来自深度残差、边界距离、有效像素覆盖和预算状态，而非任意全局减弱透镜。只对背景颜色混合，绝不在有效 UV 与原 UV 之间做过渡。类别变化不能靠平滑 UV 隐藏。

### 6. 透明层、玩家与合成边界

继续沿用宿主的一个透明表面层与前后辐射合成，不试图建立完整透明剥离。透明目标像素的表面颜色、透射和宿主折射留在既有阶段；背景查询使用 opaque 快照，禁止把已经合成的玻璃/水颜色再当背景乘一次透射。

弯曲路径中的辐射分段应根据可验证的透明表面交点确定；无法验证时沿用保守宿主合成并降低相关查询可信度，不能直接把原像素透明面距离当弯曲路径参数。必须分别验证前段、后段和近侧盘光，不能仅凭最后一张合成图宣称透明支持。

若弯曲源落在有透明覆盖、而当前快照无法重建该方向透明层的区域，则该源属于不确定背景；不增加取错层的捷径。对玩家手部、实体遮挡保持已有保护。Oculus 的 opaque 阶段可能已经含手部，需继续核对源拒绝和颜色/深度一致性；仅有深度拒绝也不能恢复手部之后缺失的世界。

在源信息不足时只回退透镜背景，保留能确定的主体辐射、核心吸收、盘面和辉光。原版 AFTER_LEVEL、Oculus 前后插入点和 EndingLibrary 后续处理顺序保持原契约。此重构不接管全局 PostChain。

## 初始性能预算（待测，不是承诺）

| 档位 | 主体求解比例 | 弯曲积分上限 | 场景深度查询总上限 | 辉光层数 |
| --- | --- | ---: | ---: | ---: |
| 低 | 0.375 | 24 | 16 | 3 |
| 均衡 | 0.5 | 48 | 24 | 4 |
| 高 | 0.75 | 96 | 40 | 5 |

场景查询总上限包含场内/场外搜索及命中细化，不是每个弯曲步骤都附加同样预算。低档更容易返回 Unresolved，这是明确质量退化，不通过放宽遮挡伪造命中。若预算导致默认场景透镜大面积退化，需调整查询策略并重新计时，不能靠少画主体获得指标。

继续投影范围剔除、GPU 资源复用和无可见黑洞零 pass；glow=0 跳过辉光。没有每帧纹理创建、同步像素回读或 glFinish。诊断采用开关控制、异步查询并限频记录阶段耗时、有效命中/退化原因；验收工具可读回，生产路径不读回逐像素统计。

## 实施顺序与文件范围

1. 先扩展 BlackHoleLensVerification：构造有可解析深度的倾斜平面、墙边、远近双层、天空边界和向上旋转相机；保留当前失败反例，建立旧实现基线。
2. 将 field.glsl 的弯曲追踪、事件终止和盘面积分拆成显式职责。以路径退出、核心命中和预算耗尽测试先行，不立即改变着色风格。
3. 添加独立背景查询 shader 模块并接入生产求解。若增加 include 文件，同步 GlProgram 加载器、独立 GPU source 加载器和 ArtifactVerification；不能只修生产 loader。
4. 调整 BlackHoleRenderer/GlTarget 的结果布局与 clear 值，更新 composite.fsh 按命中类别重建；必要时调整 GlState 纹理单元。bloom 使用的前后发光距离契约保持有效。
5. 核对原版与 Oculus 捕获内容及可验证远场层；不能把本地 EndingLibrary 新接口用于实例旧 JAR。运行所有兼容检查、完整构建和 JAR 重映射检查。
6. 固定相机/种子/时间输出前后图，RTX 3060 1080p 同上下文计时；提供诊断图和测试包，由用户手动原场景复测。

## 必须通过的验收

- lensing=0 时背景回到原始采样，无视角相关位移；普通盘光/辉光仍独立生效。
- 路径段穿过核心时精确裁剪并保留近侧盘光；直线未穿核心但弯曲路径命中也能识别；预算耗尽不能变成远场命中。
- 可解析平面/球体夹具的命中位置误差、有限深度和无遮挡性，而不仅检查“没有 NaN”。验证源 UV 确实来自路径命中。
- 相机从影响球外穿到球内，距核心多个距离；俯仰 -89° 至 +89°，左右环绕；实际旋转 VP 与 DiskNormal，不能只平移 Center 模拟所有观察角度。
- 相邻背景类别、地形/天空边缘、近面、屏幕边界、层间未知区域；无跨类别插值、无错误中间背景、无前景复制；平滑移动无显著源切换条带。
- 低/均衡/高档比较命中覆盖率与退化原因，防止“全部回退所以没出错”的伪通过；记录真实有效透镜区域并与 lensing=0 区分。
- 黑洞主体保持整墙、墙边、树叶孔洞和前景实体遮挡；保留玻璃、水的前后辐射、原版/Oculus 前后合成与终焉后处理顺序。
- 资源重载、窗口缩放、质量切换、退出世界后资源释放和 GL 状态恢复；植物补丁、命令/存档/网络保持回归通过。
