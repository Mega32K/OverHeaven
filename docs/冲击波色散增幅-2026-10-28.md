# 冲击波周围景物色散：扩大范围与加强强度

2026-10-28；相对上一版七波均启用的实现继续调整。

| 参数 | 调整前 | 当前 |
|---|---:|---:|
| 色散带单侧宽度 | max(基础半径×.45, 波半径×.18) | max(基础半径×.90, 波半径×.36) |
| 方向偏移系数 | .045 | .080 |
| 1080p 单通道偏移上限 | 40 像素 | 80 像素 |
| 普通波相对最终波强度 | 85% | 95% |
| 光谱着色混合系数 | .85 | .95 |
| 光谱颜色最低权重 | .45 | .35 |

色散带宽度恰好翻倍，颜色通道分离及光谱变色进一步加强；其它分辨率沿屏幕高度同比缩放。最大红蓝通道间距约 160 像素。解析裁剪支持范围使用相同宽度公式，防止增强范围被旧边界切掉。

仍只作用于波前周围的背景景物。七道波均启用，末端仍按波寿命淡出。保留场景深度、透明源和屏幕边界检查，无法采样时退回有效透镜背景。全屏镜头色散、冲击传播速度/终点范围、奇点/波面发光、演出时间线保持不变。没有增加体积积分步数、渲染目标或外部资源。

生产修改：FinaleWaves.java、finale_energy.glsl、composite.fsh。验证夹具 WaveRangeSpectrumGpuVerification 改为直接比较本次修改前的快照，不再以更早的“前六波被跳过”版本充当效果基线。
