# 奇点幻泡与全星空（2026-10-26）

本轮修改源码与工作区光影副本，执行针对性编译和隐藏 OpenGL 验证。没有启动 Minecraft、生成新 JAR、替换实际实例文件、修改实例配置、提交或推送。

## 视觉变化

- 移除三层错转断环。远侧改成相互连接、带空洞的彩色薄膜；材质固定在黑洞世界坐标与盘面基底中，转动视角可以看到不同结构。选取远半球作为衬景是美术分层，不是相对论求解。
- 中心采用三个紧密相交的解析泡膜与白热焦点。膜厚、干涉色相和斑块缓慢变化，不画成不透明外壳；没有添加轨道卫星或粒子实体。
- 焦点辐射增强，有限冠层进入原 HDR 金字塔；演出辉光响应为普通响应的 2.2 倍，仍由 `glow` 控制。`glow=0` 关闭屏幕扩散，直接焦点/泡膜发光保留。
- 宇宙末段的残留绕行细环也改为极暗泡膜轮廓；最后黑场仍先执行，泡膜不会打破纯黑。
- expose 初始吸积盘收束、压力前沿、逆流、片层、声音和服务端时间线保留。

## 星空来源

关闭光影时，`FinaleSky` 编译模组 `finale_stars.fsh`。开启光影时，使用 Oculus 1.8.0 的真实 `ShaderPackOptions/OptionValues` API 读取活动选项，再从当前磁盘光影包读取星点库、全星球坐标函数和原包显示转换函数，生成专用程序。模组不内嵌 Complementary 星点/色调映射源码。

这条路径直接调用包内函数，没有把最终地形颜色冒充星空纹理。演出宇宙段使用夜晚可见度，不受白天或降雨限制；星星密度 `NIGHT_STAR_AMOUNT`、曝光、对比度、白点路径、暗部去饱和、饱和度与鲜艳度读取当前活动设置。最后三片星群取自包星点的现有区域，不额外叠加模组星点。

星点经过包内显示函数进入晚期合成，不复制整套大气、云、月亮、星云、自动曝光、调色滤镜或宿主 bloom 链，因此不是整个光影天空最终画面的逐像素复刻。正常场景仍由宿主处理这些效果。

包读取/编译按活动 ShaderPack 身份缓存；切换、重载和退出销毁旧程序。未支持的光影包会记录一次诊断并将星空留黑，不回退到模组星点；关闭光影后自身星幕可恢复。

## 资源、遮挡和性能

远侧薄膜低/均衡/高档分别使用 12/20/28 次局部采样；包围球外跳过，按实际段长积分，并扩大有限采样足迹抑制条纹。三个中心泡膜各最多两个解析交点，不新增全屏体积 pass。所有近景辐射使用原 `finaleLight` 的不透明深度拒绝和透明前后分段。
