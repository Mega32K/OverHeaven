# 《群星归零》演出重制与验证 · 2026-10-27

保留奇点材质，重做它周围的演出。艺术顺序是：撤走黑色 → 召唤与压力递进 → 玻璃抵抗并破裂 → 潮水逆流 → 天穹绞紧 → 群星分批熄灭 → 黑暗与寂静 → 交还现场。参考依据为项目根目录《动画演出要求1.txt》。

本轮只修改源码、资源与文档，执行针对性编译及验证；没有生成发行 JAR、启动 Minecraft、安装模组、改实例配置、改光影 ZIP 或创建提交。默认 120 秒、八阶段 ID、服务端可调时长、自由视角、多人同步与玻璃恢复机制保留。

## 新的声画表现

| 阶段 | 演出 |
|---|---|
| expose | 原吸积盘撕成向外散失的热残弧，约 0.15 秒露出原有色散奇点。短促点火后留出空间，再让稳定蜂鸣进入。 |
| summon | 三次薄前沿在 6%、37%、66% 出发，传播窗口逐渐缩短。前沿有断口与冷金色细纹；弯曲能量束围绕固定世界方向活动。 |
| fracture | 三处实际玻璃位置向外长出主裂纹与分叉，先停顿再跨面推进，裂纹里的光落后于生长前沿。80% 的冲击使尖锐玻璃片冲出、减速，同时发生已有的 0.8 秒白闪与星空接替。 |
| reverse | 碎片按距离延迟转向，先滞住，再沿弯曲轨道坠回；能量束扭为内流。星幕角速度连续越过零点，整体逆转。音景抽走低频、出现倒卷声，在 93% 播放时间断裂。 |
| unweave | 青蓝和琥珀色的星云帷幕、暗尘带、细亮丝在整个天穹绞紧。24%、58%、84% 的时间折叠从真实奇点方向扫过天穹，配合三次压缩音；奇点仍由独立主体通道绘制。 |
| extinguish | 星轨加速，星云比星点更早衰退。黑暗按稳定种子片区扩展，三处最后星群依次退出，不同时闪灭；高频、泛音、低频分层消失。 |
| silence | 保留奇点既有的极弱末段辐射，最后 37.5% 是全黑和静音。默认最后三秒不添加字幕、闪光或结束爆炸。 |
| return | 按既有缓入缓出恢复完整世界画面、普通黑洞、环境声，最后交还 HUD／手部，不增加新宇宙诞生的解释。 |

星幕位置与速度来自同一分段积分，阶段切换不重置角度。时长命令改变实际积分区间，暂停、晚加入都从同一时间计算。白闪仍为固定的 0.5／0.1／0.2 秒，其他提示点按阶段比例缩放。没有玻璃时跳过玻璃声和玻璃几何，仍发生全维度能量冲击。

## 保留和实现边界

独立验证逐段对照修改前快照，确认以下源代码保持原样：

- 奇点半径与衰减、有孔远侧膜、中心三层色散泡膜、薄膜配色。
- 奇点焦点、高亮冠与最终冲击的局部脉冲。
- 普通黑洞的材质、透镜、采样与颜色逻辑。

新增的外围发光改变整体画面，但没有用新物体替换奇点本体。所有近景新辐射仍经过同一个不透明深度及透明前后段划分。压力前沿不写入实体球壳或不透明外壳；玻璃碎片是实例化几何，不是粒子实体。

保持“背景 → 主体及辉光 → 全屏白闪”的分层。宇宙阶段沿用远深度和单位透射率；隐藏地形不能继续遮住主体，普通世界不重复求解。同维度其他黑洞仍走已有顺序。EndingLibrary 接入位置及服务端网络、存档和现场保护未重写。

不开光影时使用本模组星点；开启光影时继续从已核对的 Complementary r5.9.3 包提取星点。新增星云、尘埃和光丝只提供演出气体层，不偷偷替换宿主星点。NIGHT_STAR_AMOUNT=0 的源星点检查通过，气体层独立存在；未知光影仍明确诊断，不回退成另一套星点。

## 主要文件

| 文件 | 用途 |
|---|---|
| FinaleChoreography.java | 连续角动量、四层声音包络与归一化提示点；只依赖共通 Java／时间线类。 |
| finale_energy.glsl | 破碎盘弧、有限压力前沿和弯曲能量流；从 field.glsl 调用。 |
| finale_cosmos.glsl | 世界方向星云、暗尘、时间折叠、稳定种子灭星片区。 |
| finale_stars.fsh / finale_pack_stars.fsh | 各自星源与共享演出气体层；宿主星源保留其实际 GetStars 代码。 |
| finale_geometry.vsh / .fsh | 尖片轮廓、外推减速及内卷轨道、分叉裂纹与薄膜反光。 |
| FinaleRenderer / FinaleGeometry / BlackHoleRenderer | 上传连续运动参数，玻璃使用 partial tick 插值，沿用现有目标与生命周期。 |
| FinaleAudio / sounds.json / sounds/finale | 新的声音调度、12 个原创声音。提示点身份包含声音名，使同一时刻的冲击与玻璃声可同时播放；停止增益不再重复相乘。 |
| GlProgram / VerificationShaders | 一致加载共享 GLSL；验证也能读取修改前快照。 |
| tools/generate-finale-audio.py / verify-finale-audio.py | 可重复的原创合成与解码、声道、峰值、循环接缝检查。 |

Java 文件位于 src/main/java/com/mega/overheaven/foliagecompat，着色器位于 src/main/resources/assets/overheaven_foliage_compat/shaders/blackhole。没有新增运行时依赖，仍是 Java 17、Forge 47.4.10、FG 远程依赖。

- 新增 910 项角位置／角速度连续性、不同阶段时长、声音包络、提示点身份、暂停和静音检查。
- 真实 NBT／磁盘恢复日志往返、中断写入和日志退役检查。

- 普通透镜近距离俯仰、环境分层与画面有限值回归。逐像素分量断言不等同于同等数量的独立游戏场景。
- 全部新 GLSL 编译和链接；原版星源与实际 Complementary 星源的上下半球、星源关闭选项、熄灭及来源切换测试。
- 完整分层白闪、暂停、晚加入计算、停止／返回合成、背向、向上、进入中心范围、其他黑洞、24／48／96 步切换、GL 状态和目标释放检查。

- 12 个 OGG 解码为有限且未削波的样本；玻璃定位声单声道，其余双声道；持续层首尾跳变不超过内部波形变化阈值。
- 360 帧时间线视频编码与完整解码通过；源码快照差异、UTF-8／空白和 git diff --check 检查。

报告中的 unsupported-pack ERROR 是刻意注入的负面测试，验证未知光影时仅输出诊断、不会切回本模组星点；不是本次执行失败。

## RTX 3060 独立 GPU 对照

输出 1920×1080，均衡档 960×540 求解，单奇点、固定相机与种子。每个阶段先交错预热 200 次，再交错测量新旧实现各五组、每组 16 帧，取中位数。两边使用相同的完整合成路径和输入。

| 阶段 | 取样时刻 | 修改前 ms | 修改后 ms | 增量 ms |
|---|---|---:|---:|---:|
| expose | 3.00 秒 | 1.312 | 1.321 | +0.009 |
| summon | 16.50 秒 | 1.390 | 1.865 | +0.475 |
| fracture | 37.80 秒 | 1.372 | 1.866 | +0.495 |
| reverse | 51.50 秒 | 1.833 | 2.428 | +0.595 |
| unweave | 75.50 秒 | 1.734 | 2.443 | +0.709 |
| extinguish | 96.00 秒 | 1.743 | 1.864 | +0.121 |
| silence | 110.50 秒 | 1.674 | 1.386 | -0.288 |
| return | 118.00 秒 | 2.267 | 1.951 | -0.316 |

这些是独立测试场景的 pass 成本，包含测试背景、主体、辉光和最终合成；不包括游戏地形绘制、宿主光影、现场扫描与恢复，也不包含实际场景的大量玻璃过绘制。不能换算成 Minecraft 帧率保证。新开销主要来自弯曲能量束和星云纹理；本轮没有新增更高步数的体积求解器。

低／均衡／高档能量束为 6／8／10 束，每束 5 段。星空和气体沿用原低分辨率目标，玻璃仍受 160／384／512 片预算约束。没有演出或没有可见普通黑洞时沿用原跳过机制，没有新增常驻屏幕后处理。
