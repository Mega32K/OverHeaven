# 梦幻长曝光星空 · 2026-10-29

按用户提供的星轨照片调整演出星空：细长连续轨迹、近白线芯、冰蓝与淡紫柔边，少量粉色和暖金点缀。星芯保持锐利，固定少量亮星增加有限柔光。黑洞、奇点、泡膜与主体辉光继续在星空之后绘制。

## 亮度与颜色

- 星芯辐射为旧版无尾迹星点基准的 1.6 倍，开启曝光时不再降到 40%。色调为近白色，稳定身份决定淡色倾向，不随时间闪烁。
- 尾迹基础预算为旧版尾迹的 1.8 倍；整条轨迹乘 `1 + 23*smoothstep(0°,20°,实际天球弧长)`。实际弧长是旋转角总路程乘恒星距旋转轴的正弦，包含反向时的来回路程，补偿上限 24。
- 反转和极点附近使用 `smoothstep(0.04°,0.35°,实际弧长)` 退掉尾迹；星芯自身保持稳定，不把收成一点的整条尾迹叠到头部。
- 快门曲线前 70% 保持等强，后 30% 使用 smoothstep 退零，积分归一化为 1。每段分配自己的积分区间，片元沿线校正为连续权重，消除分段亮度阶梯。
- 最亮四分之一使用完整快门；其余由恒星方向与演出种子确定为 55%～85%。每颗星的快门比例稳定，不按帧随机。
- 亮轨柔边宽度为线芯 sigma 的 2.4 倍，积分预算为线芯的 35%，在 3.5 sigma 的有限几何范围内绘制。使用宽度平方归一化，宽边不会隐式获得无限额外光量。
- 星表按亮度降序排列，固定前 64 颗具有星点光晕；各档名单相同。1080p 光晕半径由亮度在 4～12 px 内插值，幅度为 `StarFlux*0.065`，半径外严格为零。按画面短边缩放。

倍率均指 shader 辐射，不等于最终显示亮度倍数；保留当前原版/光影及晚期合成的色彩空间约定，没有全屏调亮或对预览另外加曝光。银河纹理与 85% 当前/15% 短曝光采样保持原样。

## 时间与实现

沿用原有星幕转速、25/80/200 ms 阶段快门、24° 最大旋转路程与末段曝光收短。八阶段时长、后续冲击波、白闪和熄灭节奏没有修改。

| 阶段 | 表现 |
|---|---|
| 星空显露～44 秒 | 亮星点和短尾；少量星点柔光 |
| 44～60 秒 | 尾迹随旋转先收短再反向展开 |
| 60～88 秒 | 长轨逐渐建立，明暗和长短分层 |
| 88～98 秒 | 连续长轨高潮，随后被当前方向溶解场切开 |
| 98～108 秒 | 曝光与最大角路程共同退零 |
| 108 秒以后 | 星点、尾迹与光晕均无残留 |

`FinaleStarExposure` 每帧按同步时钟生成固定 65 点的历史角度与累计路程表，不保存画面历史。shader 依据各星快门比例在时间表内取值，避免直接缩放旋转角导致加速和反向轨迹错误。星轨几何仍为低/均衡/高档 4/8/12 段，恒星数量仍为 1,024/2,048/4,096。

共享 `finale_star_style.glsl` 提供稳定配色、快门积分、弧长补偿和有限光晕。生产 shader 加载器及独立验证加载器均显式支持该 include。绘制继续使用原来的批次和渲染目标，没有增加纹理、模糊金字塔或跨帧缓存。

每段独立进行近裁剪和视野裁剪，并为柔边预留有限支持范围；不钳制屏外轨迹。源恒星消失时停止整条贡献，每个最终片元再次检查当前方向溶解场，光晕不会填回已溶解区域。

NASA 失败时继续使用程序短星轨路径，同步提亮、采用相同冷白微彩配色和逐像素溶解约束，不为备用路径增加多次全屏星场求值。
